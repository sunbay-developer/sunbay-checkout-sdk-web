Sunbay Checkout SDK — 主题 / colorScheme Demo

SDK iframe 的配色由商户控制，默认浅色。下方「初始配色」在初始化时随 createCheckout 的 appearance.colorScheme 传入；初始化后用「运行时切换」按钮调 updateCheckout 动态切换，观察卡字段配色实时变化（卡值始终只在 iframe 内，父窗口只发配色补丁）。

两种接入方式的配色都由 appearance.colorScheme 控制：初始配色随 createCheckout 传入， 运行时用下方按钮切换。选择后点「① 创建订单并初始化」挂载对应方式；切换方式需重新初始化。

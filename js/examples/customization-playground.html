定制 Playground

改动控件 → 点「应用定制」即调 updateCheckout 实时下发，观察右侧卡字段 / 钱包按钮变化。初次请先「创建订单并初始化」。

连接 / 接入

colorScheme

appearance.variables

留空=不覆盖（用托管默认）。颜色用取色器；清除点「×」。

appearance.rules（JSON）

针对锚点的 scoped 覆盖。key 为 target（input / input:focus / input:invalid / label / error / cardBrand / cvvIcon），value 为属性对象。非法值会被托管侧白名单丢弃。

钱包按钮（expressCheckout）

品牌按钮走 expressCheckout 参数（非 appearance）。buttonType 为各钱包官方全集； buttonHeight 全局 clamp 到 [30,64]。改后需重新初始化 express（见「应用钱包按钮」）。

点「① 创建订单并初始化」开始。

卡字段预览

钱包按钮预览 (expressCheckout)

钱包按钮是否渲染取决于会话允许 ∩ 环境可用（真机 Apple/Google 条件见 README）。 普通浏览器可能不渲染，属预期；可观察控件透传是否无报错。

Sunbay Checkout SDK — Examples

Interactive, runnable samples of @sunbay/checkout-sdk-js. Each page drives the real published SDK (window.SunbayCheckout) against the hosted runtime, with a tiny dependency-free backend that creates sessions using a sandbox merchant key.

1 · Full card Element

The simplest embedding: a single combined card Element (number + expiry + CVC in one iframe), then confirm().

2 · Split fields + address

Lay out cardNumber / cardExpiry / cardCvc in separate slots, combined with a billing and a shipping address Element.

3 · Theming & customization

Global theme (appearance.variables), element-level rules (appearance.rules & per-element isolation), and live hot-reload via updateCheckout().

Prerequisites: build the SDK (pnpm --filter @sunbay/checkout-sdk-js run build), start the hosted runtime (checkout repo's npm run dev on :3000), and fill example/.env.local with sandbox credentials. See example/README.md.

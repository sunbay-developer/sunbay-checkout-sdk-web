1 · Full card Element

A complete single-page checkout. The merchant page creates a session, calls createCheckout(), then mounts three Elements — an expressCheckout wallet row (Apple Pay / Google Pay), a combined card Element (number + expiry + CVC in one hosted iframe), and a billing address Element — and finally calls confirm(). Card data stays inside the hosted iframes and never touches this page.

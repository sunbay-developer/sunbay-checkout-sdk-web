2 · Split fields + address

Instead of a single combined card, lay out the three split fields (cardNumber, cardExpiry, cardCvc) in separate slots so you control the layout, then add a billing and a shipping address Element. Split fields and the combined card are mutually exclusive; each split field type is a singleton. The shipping address requires a session created with collectShippingAddress:true. Note the merchant-owned “Delivery options” block inserted between the two address Elements — each Element is an isolated iframe, so you can freely interleave your own page content.
